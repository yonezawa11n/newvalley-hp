# 採用サイト用の写真フォルダ

採用サイト（/careers/）で使う写真をここに置いてください。
GitHub の画面で「Add file → Upload files」からアップロードできます。

内容ごとにフォルダを分けると、配置がスムーズです（アップロード時にファイル名の前に `staff/` などと付けるとフォルダが作られます）。

| フォルダ | 入れる写真 |
|---|---|
| `staff/` | スタッフの人物写真（インタビュー用など） |
| `work/` | 仕事中・支援中の様子 |
| `office/` | 事業所の外観・室内 |
| `event/` | 研修・イベント・集合写真 |

- ファイル名は半角英数字がおすすめです（例：`staff/ogawa-2.jpg`）
- 写っている方の掲載許可を取ったものだけを置いてください
